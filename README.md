# ElevenLabs Scoop Bucket

Scoop manifests for the [ElevenLabs CLI](https://github.com/elevenlabs/cli).

## Install

```powershell
scoop bucket add elevenlabs https://github.com/elevenlabs/scoop-bucket
scoop install elevenlabs
```

---

> This repository is maintained automatically by the ElevenLabs CLI release
> pipeline. The manifest is generated and updated on each release — please do not
> edit it by hand.
